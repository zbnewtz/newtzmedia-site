# NewtzMedia website

Marketing site for NewtzMedia: social media posts for local small businesses,
for a monthly fee.

Current stage: two design-direction mockups, in `mockups/`. Open
`mockups/minimal.html` or `mockups/interactive.html` in a browser. No build
step. The design spec is in `docs/superpowers/specs/`.

Sample work in the mockups is fictional except NFTek.
